PROPOSED RECONCILIATION, NOT APPLIED
Assume long-only portfolios, no leverage, and zero-duration cash. Let Dc be credit
duration, Dt short Treasury duration, and H the nonnegative liability horizon.
When Dt <= H <= Dc:
  Credit weight = (H-Dt)/(Dc-Dt)
  Treasury weight = 1-Credit weight
  Cash weight = 0
When 0 <= H < Dt:
  Credit weight = 0
  Treasury weight = H/Dt
  Cash weight = 1-Treasury weight
Portfolio duration = Credit weight*Dc + Treasury weight*Dt + Cash weight*0.
If H exceeds Dc or input durations are missing/nonpositive, flag infeasibility
instead of silently clipping weights. This specifies one feasible allocation
policy, not a uniquely optimal three-asset portfolio.

Using row 4's supplied durations and H=7 gives Aaa credit 36.95065466% and Baa
credit 44.11464570%; complements go to short Treasuries. Both sum to 100% and
match seven years within floating-point precision. Original rounded allocations
produce 7.00628981 and 6.9877598 years respectively.
If the intended cash instrument has nonzero duration, specify it and use the same
explicit convention for both portfolios before applying the reconciliation.

3. COUPON UNITS — CONFIRMED, BUT MODEL CHOICE MATTERS
'Part 1 Immunization' B10 stores 0.0398 (3.98%). B23 is
  =$B$16*($B$10%)/2
The extra % divides by 100 again. With B16=$37 million, the cached payment is
$7,363. For a hypothetical bond whose annual coupon rate is 3.98% on that
notional, =$B$16*$B$10/2 yields $736,300 per half-year.
The same extra conversion affects C23:C27, B23:B36, J23:J36, K23:K27 and the
corresponding coupon formulas in 'Port Test'. Principal additions need to remain
separate when correcting coupon terms.

Do not simply add those corrected coupons to index-based performance. These are
total-return index series; a backtest using changes in total-return index levels
must not add the same coupon return again. Choose one coherent approach:
  a) index-level return simulation using index units and observed durations; or
  b) an explicitly hypothetical bond cash-flow model with consistent coupon,
     price, maturity, yield, and reinvestment conventions.
The source mixes index levels with individual-bond par and maturity assumptions.
Its index price divided into $1,000 bond counts is not an established replication
of the index. Rolling bond indexes do not mature like individual bonds.

4. INITIAL FUNDING — REQUIRES MODEL RECONCILIATION
'Part 1 Immunization' B16:C16 and J16:K16 allocate the full $100 million future
liability (G4), rather than its present value. At the workbook's nominal annual
2.5% rate with semiannual compounding over seven years, the illustrative PV is
100,000,000/(1+0.025/2)^14 = $84,036,809.06.
That compounding convention follows the workbook's cash-flow formulas; it is not
a verified historical liability discount curve. Define the liability discount
method explicitly, then distinguish initial capital, liability PV, and surplus.
The report's claim of initial PV matching is not demonstrated by these positions.

6. OTHER MODEL QUALITY ISSUES
'Bond Port 1 ' and 'Bond Port Semi' B18:C18/N18:O18 subtract squared duration error
from squared price error. Minimizing that objective can reward larger duration
error. If retaining a calibration model, define properly scaled nonnegative
errors and constraints; do not equate index levels with bond prices.
Those draft sheets also mix coupon units and maturity assumptions. They should
not be featured as validated model outputs.
The historical worksheet inputs and the end-2025 base instrument snapshot must
not be interchanged when constructing the end-2018 portfolio.
